# Helciny podcasty pro PocketBook InkPad 4

Nativni katalog pro online poslech tri poradu: Karlikovy minecrafticke pohadky, Minecraft pribehy na dobrou noc a Same otazky. Epizody `BONUS` jsou u Karlikovych pohadek skryte. Obrazky se ukladaji jen do male lokalni cache; audio se prehrava online pres systemovy prehravac PocketBooku.

1. Z GitHub Actions stahnete artefakt `HelcinyPodcasty-pocketbook-app`.
2. `HelcinyPodcasty.app` zkopirujte do slozky `applications`.
3. Zapnete WiFi, spustte aplikaci a zvolte `OBNOVIT KATALOG`.

Prepinac `Dalsi dil` pouziva rezim PocketBook `MP_ONCE` nebo `MP_CONTINUOUS`. Funkcnost prehravani HTTP/HTTPS streamu zavisi na firmwaru InkPad 4; pri prvnim nasazeni ji overime primo na ctecce.
