# Jakubův přehled pro Android

Domovský widget s Jakubovým rozvrhem, suplováním, testy a úkoly. Přihlášení probíhá přes zabezpečený rodinný server. Heslo se neukládá; telefon šifrovaně ukládá pouze dočasný přístupový token.

Po instalaci otevřete aplikaci, přihlaste se Jakubovým účtem EduPage a poté přidejte widget **Jakubův přehled** na domovskou obrazovku. Widget lze měnit přibližně mezi velikostmi 5×2 až 5×4; ve větší variantě ukáže více sekcí.

Data se automaticky obnovují přibližně každých 30 minut a ručně klepnutím na **Aktualizovat**. Po restartu rodinného serveru se kvůli ochraně údajů přihlaste znovu.
