# Astro Pi Mission Zero

Jednoduchý základ pro děti: Astro Pi změří barvu okolního světla, použije ji
jako pozadí, zobrazí raketu a pošle pozdrav posádce ISS.

## Spuštění v emulátoru

1. Otevři [Mission Zero starter project](https://rpf.io/mission-zero-starter).
2. Vlož obsah souboru `main.py` do editoru.
3. Spusť program a sleduj LED matici.
4. Uprav obrázek, barvy nebo krátký pozdrav, aby byl program vlastní.

Program pracuje se senzorem barvy a jeho běh je kratší než 30 sekund. Před
odesláním je nutné použít aktuální kód třídy a zkontrolovat oficiální pravidla.
