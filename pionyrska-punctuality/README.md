# Dochvilnost Pionyrska

Web a prubezny sber skutecnych rannich odjezdu mezi 7:00 a 8:15 linek 25 a 26 ze zastavky
Pionyrska, stanoviste 6, smer Capkova. Staticky jizdni rad a polohy vozidel
pochazeji z otevrenych dat IDS JMK.

Sluzba posloucha na portu 8097. Skutecny odjezd se zaznamena pri prechodu
vozidla k nasledujici zastavce Botanicka (`U01262Z04` v dynamickem feedu).
